# Frisdahl Studio

## Project Type

Alexander's own web design and development studio site. Business site and portfolio piece.

## Purpose

Presents the studio's services (web development, design), process, pricing and case studies. Visitors can get in touch through a contact drawer with a booking picker. Supports Danish and English (`LocaleContext`).

Relationship to Portfolio 2026: Frisdahl Studio is the business-facing site and Portfolio 2026 is the personal portfolio. Keep their roles distinct so they don't compete.

## Technology

- React 19, TypeScript, Vite
- Tailwind CSS 4 (via `@tailwindcss/vite`)
- React Router 7
- Framer Motion, Lenis (a light smooth scroll for mouse wheels only, `lerp: 0.18`, in `src/lib/scroll.ts`; see `Progress.md`)
- GSAP (added 2026-10-27 at Alexander's request for smoother hover/interaction timelines; first used in `CtaPillButton`'s `fillOnHover` variant on the header contact button, merged into `master` 2026-10-27)
- Fonts: Manrope (site) and Montserrat (only for the Nordwear type specimen; it's NordWear's own typeface), both self-hosted via `@fontsource-variable/*` (Montserrat added 2026-10-28, branch `ai/project-hero`). No Google Fonts requests.
- ESLint (no tests yet)

There's no backend and no environment variables.

## Project Instructions

The repository has its own `AI_CONTEXT.md`, the original brief: goals, design style, structure and coding standards. Read it before working on the project. Its colour palette is out of date compared with `src/index.css` (see `Progress.md`).

## Architecture Notes

- Content lives in typed data files (`src/data/*.ts`, types in `src/types/`), separate from components.
- Motion logic is split into hooks (`src/hooks/`, e.g. `useStickyScrollSteps`, `useHorizontalDragSlider`, `useFixedNav`) and helpers (`src/lib/`).
- Pages are thin. Sections live in `src/components/sections/`.
- Booking (`src/lib/booking.ts`) only computes available dates on the client. Nothing is sent anywhere.
- The contact form doesn't submit (`onSubmit` calls `preventDefault`). Contact currently happens through `mailto:` links.
- The fixed header is transparent. A section with `data-header-theme="dark"` switches it to its light variant (`.site-header.is-on-dark`, set by `Navbar`) while the section is behind it. Mark any new dark section this way. (The home cases section used it while it was black; it now turns from black to white as it rolls in, so no section currently uses it.)
